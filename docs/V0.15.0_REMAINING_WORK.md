## 已完成范围

### Echo 命令与引导工作流

- Echo 私聊和群聊提及场景会严格识别已注册命令；未知命令、普通斜杠文本和非 Echo 会话仍按普通消息发送。
- 已接通命令结果、互动卡片和 `workflow.start`，支持 `/need`、`/feedback`、`/publish`、`/help`、`/list` 和 `/cancel` 等既有命令定义。
- 引导流程支持继续、确认、完成、取消、过期、冲突恢复和终态清理；关闭后恢复原消息输入焦点。
- 命令与附件冲突时保留消息草稿和附件；未提交工作流草稿按标签页会话暂存，登出或 Workspace 清理时移除。
- React StrictMode 下重复 effect setup 会复用同一 invocation，不再因 cleanup abort 留下永久 loading。
- 服务端已补活动工作流唯一约束、`clientInvocationId` 幂等、请求哈希冲突、持久化限流、完整 Bot 会话上下文、CAS 竞态检查和不含正文的审计。
- `/cancel` 未提供工作流 ID 时，会按当前操作者、会话和 Bot 定位唯一活动工作流，并返回稳定的 missing/ambiguous 错误。

### 群聊话题

- 群聊首段纯文本 `#[标题](正文)` 会在消息创建入口原子转换为话题和创建卡，不再额外保存原始语法消息。
- `clientMessageId` 同时作为话题幂等键；原子入口创建的话题允许成员选择把话题消息同步到群聊。
- 话题支持创建、加入、退出、独立消息流、通知偏好、未读、同步、取消同步、关闭和归档。
- 同步投影使用通用卡片注册表；取消同步会使卡片失效、删除群聊投影，并通过实时事件让已打开的另一客户端移除旧投影。
- 关闭和归档使用 revision/CAS，权限、事件、保留清理和审计边界与 Workspace 现有模型一致。

### 自定义 Agent Bot 与 Gateway

- 新增 `@duallane/agent-sdk` 0.15.0，支持 REST、WebSocket hello/heartbeat/ack、有限重放、重连、上下文、消息、卡片和 OpenClaw bridge。
- 发布通用、OpenClaw、Hermes 的 stable/v1 Prompt，并用 SHA-256 manifest 固定 v1 内容。
- Nginx 为 stable Prompt 配置 5 分钟缓存，为 v1 配置 1 年缓存，并启用 ETag 和 Last-Modified 条件请求。
- Gateway 上下文读取复用会话成员和 grant 校验，并执行时间窗、回复/系统消息开关、消息数、字符数和保守 Token 上界。
- Bot 所有者可在 `allowDirect=true` 时创建与自己 active Bot 的私聊；默认 trigger grant 开启、context grant 关闭，显式授权后才可读取上下文。
- Token Scope、会话授权、群聊策略、撤销即时失效、幂等、限流和拒绝审计均由服务端执行。
- 受控飞书 Card 子集已接入发送、更新和动作管线；脚本、HTML、私网 URL、未知动作和超限载荷会被拒绝。
- 未注册卡片类型安全显示消息发送时的不可变 fallback；可变 revision 和最新状态保存在独立卡片注册表中。

### 浏览器与视觉验收

- 新增 Topic 双用户完整流程 E2E。
- 新增 Echo 普通消息、命令、完成、Escape 取消、焦点恢复和 StrictMode E2E。
- 新增 Agent Bot 的 UI 创建/配置、owner direct、Scope 拒绝、卡片 revision、群聊拒绝、Token 撤销和 401 E2E。
- 新增 v0.15 响应式视觉检查，覆盖 `1440x900`、`1024x768`、`390x844`、`360x800`、浅色、深色和 `prefers-reduced-motion: reduce`。
- 视觉检查断言无横向溢出、交互面板不越界、主操作触控高度至少 44px，并生成四个目标截图。
- 新增用例会清理活动工作流、临时 Bot 和临时成员，完整套件不依赖执行顺序。

## 发布前操作

以下是发布流程，不是剩余开发缺口：

1. 审查本工作树的完整 diff。
2. 提交并推送开发分支，通过项目约定的合并流程进入 `main`。
3. 在 `/home/timestarry/duallane` 执行 `git pull --ff-only`，确认得到精确的 `origin/main` 提交。
4. 仅从该生产检出运行 `deploy/production/deploy.sh`，等待候选 API/Web 容器健康后再替换现有容器。
5. 完成生产登录、Workspace 启用门禁、Echo、Topic、Agent Bot、P2P 私密通道和回滚点冒烟验证。

## 不可破坏的边界

- P2P 私密通道的消息和文件明文不得进入服务端持久化或日志。
- `#k=` 邀请片段只能停留在浏览器端。
- Workspace 必须继续由 `WORKSPACE_ENABLED=true` 显式启用。
- Workspace 改动必须保留 RBAC、配额预拒绝、消息保留和审计规则。
- 不得削弱 Fastify 日志脱敏、Bot 鉴权、卡片动作权限或安全响应头。
