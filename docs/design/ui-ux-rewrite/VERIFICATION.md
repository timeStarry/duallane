## 已复现并修复：开关圆点偏移

原始 V2 在 Chromium、320px、原色浅色、关闭状态下测得：按钮起点 x=235，
轨道 x=241，圆点 x=238。轨道相对命中区右移 6px，圆点左侧超出轨道 3px。
同一断言在未修复原型上失败，修复后通过。

原因：按钮的浏览器默认水平 padding 与普通流轨道、绝对定位圆点使用了不同原点。
修复：清除默认 padding，固定命中区与 flex 尺寸，将轨道和圆点放入同一定位坐标系。
轨道 44×26，圆点 20×20，开启和关闭端点间距均为 3px。

新增交互在检查中修正了三个边界：打开前已排队的滚动通知不能立刻关闭新菜单；
快速重复返回时，旧 dialog 的异步 close 事件不能清空新确认框的动作；
失败状态重试后更新反馈不能丢失键盘焦点。另修正历史条目缺失设置索引时一次性放行标记的清理。
这些路径均有原型回归检查；保存竞争只验证本页模拟，不代表真实服务端并发已经验收。
