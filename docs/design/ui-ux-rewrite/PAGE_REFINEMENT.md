## 页面与行为

| 反馈 | 正式实现与验收目标 |
| --- | --- |
| 详情按钮与关闭图标偏移 | 根因是 `.desktop-only` / `.mobile-only` 将 grid 改为 flex 后，原 `place-items` 不再负责横向居中。图标按钮显式使用双轴 flex 居中，清除内边距，保留 44px 命中区；检测图标和按钮中心差不超过 1px。 |
| 群邀请仍是内嵌列表 | 侧栏只显示当前成员、搜索和“邀请成员”入口。独立 `MemberPickerDialog` 提供搜索、多选、已选数量、取消、提交与内联失败。已在群内的人不在候选中；无管理能力时无入口。 |
| 侧栏结构陈旧 | 桌面 360px 详情列，标题和标签固定、正文独立滚动；平板使用抽屉，手机进入整页详情。概览分成身份、会话摘要、常驻消息与话题入口，不再嵌入重复的完整话题列表。成员行只保留一个更多入口，复用右键、长按和键盘动作。 |
| 导航重复与中栏占位 | 普通成员主导航为聊天、话题、文件、成员、个人；管理角色增加空间入口。中栏只用于聊天和话题，可折叠且保留未发送内容。文件、成员各有一份主列表及搜索。账号菜单保留配额、重新同步、返回入口和退出；手机退出位于个人首页。 |
| 话题与设置层级混乱 | 话题标题、紧凑状态和工具栏重新分层，状态不占满整行。个人资料区分编辑、保存和只读身份；通知、邮箱与偏好用扁平分组。Bot 的资料/连接/授权/凭据，Echo 的需求/公开征集采用同级章节，切换保留草稿。空间权限和可见范围支持成员搜索。 |
| 主题缺少直观预览 | 正式外观设置使用原色、苔原、暮色的微型产品预览，配色来自实际主题 token，并跟随浅深模式。选中与焦点保持独立，换主题不重建业务页面。 |
| 相册切换细长 | 共用 `ViewModeSwitch`，列表和卡片各有 44px 操作目标，图标与文字同时出现。相册卡片补充文字内距、分级和网格间距，桌面最小列宽 220px，手机两列。 |

文件、成员页未选对象时不显示上次会话的详情；选择文件后才打开文件信息。
平板抽屉显式退出桌面 grid 列定位，避免取消中栏后落到屏外的隐式第三列。
页面检查同时验证抽屉实际在视口中及关闭按钮可点击，不能只根据 DOM 可见性算通过。

## 邀请、实时更新与权限

邀请复用现有单成员 POST 协议，按所选顺序提交，不承诺原子批次。
成功项立即更新会话成员，失败项保留选择；重试不会重新提交已成功的成员。
账号、会话、访问权限或所在页面失效会关闭弹层并中止后续操作；迟到响应不能改写新上下文。
取消未提交的选择不发送写请求；提交中锁定选择和关闭控件。

真实 Go 回归复现了模拟数据未暴露的问题：`message.created` 的会话投影不含 `capabilities`，
直接覆盖 HTTP 会话快照会暂时清除管理能力，进而卸载邀请弹层。
前端现在即时合并消息/成员的增量；缺少能力字段的会话投影通过现有、带账号及访问代次校验的
HTTP 刷新补齐，不当作完整快照覆盖。明确的禁止能力仍立即生效，后端权限检查保持原样。
代价是这种事件批次可能增加一次会话列表读取；没有修改后端协议或引入第二个写入者。

事件补齐也复现了重连期间的已读时序：消息已到达底部时连接仍在同步，滚动处理没有发送已读请求。
恢复连接或未读数更新后，现在重新检查真实可见的聊天列表，仅处于底部时补交已读；
不主动移动阅读位置，后台页、手机详情和其他视图不能因此提前清除未读。
完整双用户消息、历史、文件和重连测试保留原有断言验证这一行为。

空间入口的隐藏是导航简化，不能代替服务器授权。历史空间深链接保留只读摘要兼容。
角色、可见范围、Bot 授权、配额与审计继续使用现有能力和 API。
主题和布局调整不改变 P2P 的正文、文件与 `#k=` 秘密边界，没有数据库迁移。

## 主题选择与退出入口精修（2026-09-11）

个人设置的退出按钮原先是未设置圆角的原生按钮，局部透明背景又与全局危险操作背景
竞争。现在直接复用共享 `Button` 的危险变体，保持 10px 圆角、44px 命中区、悬停／按下
及键盘焦点。账号弹出菜单的行也使用控件圆角和 44px 高度，退出项恢复危险操作色。
原退出回调与未保存资料确认逻辑不变。

主题增加米色和极简，各自提供完整浅深色。米色使用暖灰米白底面及蓝灰／棕褐强调，
极简使用黑白灰表面和控件，并保留成功、警告、错误语义色。原三套主题和已有偏好继续适用。
生产注册表同时驱动偏好校验和工作台，新增主题不需要另一份手工选择白名单。
参考与配色约束记录在 [设计系统](DESIGN_SYSTEM.md)。

`ThemePicker` 保留实际主题预览、标题和选中标记，移除小字描述与默认徽标。
所有尺寸都沿单行横向排列，保留下一张卡片的局部可见提示及左右浏览按钮。
触摸与触控板使用原生滚动；鼠标拖动不提交选择；方向键／Home／End 浏览焦点，
Enter／Space 才选择。重新进入时选中卡片完整可见，仅调整条带横向位置。
移动端曾复现“最小距离滚动被吸附拉回，选中项仍被裁切”，已改为对齐卡片吸附起点。

## 表情设置路由修正（2026-09-11）

原实现以 `accountSection === "emotes"` 直接挂载管理弹窗，关闭又导航至聊天设置，
使正常分类页面无法被访问。修复将弹窗改为独立临时状态：分类导航、深链接和刷新
只显示设置页；明确点击“管理我的表情”才打开，关闭与 Escape 不写入路由或历史。
浏览器导航、退出清理弹窗；聊天入口在原会话上打开，关闭保留草稿并恢复原触发项，
表情选择器已卸载时回到编辑器。路由已变化时不恢复上一页面的焦点。
关闭回调保持稳定，普通应用重渲染不再重复初始化管理弹窗和焦点。

新增回归在修复前稳定复现“预期没有弹窗，实际自动出现一个”。修复后，独立 Go
测试服务的 4 项聚焦流程通过：三种宽度的设置分类／关闭／刷新／前进后退，表情订阅，
合集删除取消与保留内容，以及管理布局／聊天草稿／焦点和合集预览。既有表情测试
更新为先点击显式管理入口，原业务断言继续保留。

已人工查看 1440px 和 390px 设置页面，320px 也通过页面与焦点检查。
Web 298 项、SDK 8 项、离线兼容 20 项通过，后者原配置另跳过 1 项；类型检查和构建通过。
本轮没有改动表情资产、表情数据接口、存储、权限或 P2P 行为。

## 导航占位、输入材质与按需详情（2026-09-11 后续）

文件和成员没有中栏时，原 `display:none` 会移除顶部折叠按钮，让其余主导航上下跳动。
现保留固定 44px 槽位并禁用按钮，仅聊天/话题可折叠；禁用项不宣称控制一个不存在的区域。
输入区外围 dock 透明，不再形成大于输入器的一块底板；主题底色、边框、阴影与圆角只用于输入器本体。
移动端继续保留底部间距和已有 safe-area 规则。

显示模式恢复为浅色、深色、跟随系统三个直接可见的选项，使用统一 SelectionItem 的细边线/圆角。
同一 radiogroup 只有一个 Tab 停留点，方向键/Home/End 可选择，偏好保存和跟随系统解析不变。

话题默认只保留标题、状态、所属群、人数和“话题详情”入口。
说明、提醒、加入/退出、关闭/归档集中在按需打开的详情层；桌面右侧，手机整页。
沿用真实成员和管理权限，关闭/Escape 归还焦点，切换话题不会残留上一层。
消息能力的完整共用与本次证据见 [会话一致性](CONVERSATION_PARITY.md)。
