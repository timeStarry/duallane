01 / DIRECTION

特色来自产品逻辑，
精致来自每一次细节一致。

DualLane 的独特之处，是让用户在开始沟通前选择内容的去向。把这一点变成稳定的品牌语法，让所有页面都使用同一套新设计。主题提供个性，产品语义保持稳定。

推荐 · 清晰双轨
01 — IDENTITY

双轨识别

默认主题以铜橙标识私密直连，以青蓝标识共享空间。其他主题可以重新配色；图标、名称与保存说明始终保留。

02 — CLARITY

内容优先

以中性色承载长时间阅读。留白与底色划分内容，输入区轻微抬起，顶栏局部半透明，浮层具有柔和且清楚的高度。

03 — CONTINUITY

状态连续

对话、文件、话题、Bot 遵循统一的操作语法。按压、发送和展开有连续反馈；切换主题不重置会话、草稿或阅读位置。

已有品牌记忆，应该保留并收敛

现有 Logo、私密直连与共享空间已经使用铜橙／青蓝。默认主题保留色相与双轨形态；所有主题采用一致的精细轮廓、阅读比例与层次规则。

02 / FOUNDATIONS

一套语义，两个通道。

颜色按用途命名，组件读取语义值。每组主题都有成对的浅深模式；轮廓与操作状态由统一规范定义，密度只调整间距。

字体与阅读节奏

沿用系统无衬线字体栈；数字与容量使用等宽数字。中文正文建议 15px / 1.7；避免通过缩小字号解决布局拥挤。

03 / MATERIAL & THEMES

让气质改变，
让熟悉的体验留下。

三组主题共享同一套组件、轮廓、层次和操作。每组都有完整明暗版本，切换会立即作用于整份报告与产品样例。

试试材质与手感

滚动聊天查看顶栏，发送消息或打开详情感受过渡。

柔和层次

正文平整、输入区轻抬、浮层悬起。用底色与精确的双层阴影表达高度，让边框退出不必要的位置。

局部半透明

只让覆盖内容的顶栏与遮罩呈现材质。这里是 Web 模糊近似；无模糊支持或关闭效果时使用实色底层。

连续反馈

按压 120ms，消息进入 180ms，面板展开 200ms。主题变化不重建会话；系统减弱动态始终优先。

设计依据：WhatsApp 的中性色与图标细化、Discord 的形状语义与输入栏整理、Apple 对材质层级与克制使用的说明。本提案采用自己的比例与动效参数。

默认主题延续铜橙与青蓝；替代主题可以使用不同配色。私密直连与共享空间仍通过名称、图标及保存说明辨认。主题不会改变权限、保存位置或消息内容。

本页为 V2 视觉与组件基线，未接入产品服务。完整导航、话题与私密直连流程以重构体验规格为准；当前样例不代表全页面重写已完成。

让每一次沟通，都顺手一点。

切换主题与屏宽，输入多行消息，打开会话详情。留意字体、头像轮廓、输入区的轻微承托，以及顶栏与消息的连续反馈。

消息发送、附件、Bot 身份与话题入口遵循统一格式。失败发生在对应消息旁，不打断整段交流。

主题负责气质

主题提供背景、文字、控件、通道与材质的成套取值。组件只使用“正文”“浮层”“主操作”等语义 Token，不依赖某个色名或主题特例。

基础数值 → 主题语义 → 组件样式

偏好独立组合

主题、浅／深／随系统模式、舒适／紧凑密度、标准／减弱动态分别设置。换主题不会重置字号、密度、动态偏好或会话状态。

theme × mode × density × motion

稳定的主题契约

为主题设定 schema 版本与必需语义字段。未知主题或不支持的版本回退默认主题；缺失必需语义值的主题不得发布，可选值采用统一默认值。新主题复用同一组件库，不引入独立页面皮肤。

每套主题都可读

每个主题验证浅深模式、正文与控件对比度、焦点、禁用和错误状态。高对比度与减弱动态偏好优先；无法使用模糊时采用稳定的实色底层。

共享语义，映射到各端

Web 将语义映射为 CSS 变量；未来原生端映射为平台颜色、字号、材质与动效。导航、返回、分享和文件选择遵循各端习惯，交互结果保持一致。

颜色可以变化，信任边界不会变化。“私密直连／共享空间”的名称、图标和内容保存说明始终保留，不能仅靠配色区分。私密直连内容不由服务器保存；共享空间按空间规则保存并受权限、配额和审计约束。

以上是新架构的设计契约。报告提供主题与布局样例；完整主题组合、平台系统设置、真机键盘和原生映射仍需在产品实施时验收。

01

冻结全套体验与主题契约

先确定全部页面、关键状态与共用组件，更新项目设计规范。新基础组件直接使用语义 Token；尺寸、材质、动效与可访问性一起定义。

02

围绕新架构重写全部页面

按模块组织实现，共享消息、编辑器、文件、表单和反馈基础。统一替换旧样式与旧组件，不建立长期旧组件兼容层。

行为门槛逐项验证现有能力、草稿、中文输入法、长内容、失败重试、重复事件与重连。API、数据模型、权限、配额、保留和审计契约保持不变。
03
