01 / 可发现

每条消息都有“更多”

右键与长按是快捷入口。键盘可聚焦消息后按 Shift+F10，手机也能直接点击按钮。

02 / 有边界

保留文字的原生手感

正文与链接可以选择、复制；拖动、滚动或第二根手指会取消长按。不会全局接管浏览器菜单。

03 / 说清影响

隐藏、撤回、移除各有含义

隐藏只影响自己。撤回影响共享消息；移除文件影响可用性。菜单先展示动作，重要操作再确认。

试试对消息空白处右键，或使用“更多”按钮。
