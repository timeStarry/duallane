# 待发布：清晰双轨 UI/UX 重构

这是当前开发分支的发布说明草稿，包含首轮重构后的真实页面结构精修，尚未分配正式版本或发布日期。具体修正和证据见 [页面精修](PAGE_REFINEMENT.md)。准备产品发布时，将审核后的内容纳入既有 release catalog，并同步 Web 与根版本；不把未发布功能写入当前 0.18.0 的历史记录。

- 入口、聊天、话题、文件、成员、个人与空间设置采用统一的清晰双轨语言。细线选中标记与圆角边框形成同一套导航规则。
- 提供原色、苔原、暮色、米色、极简五组主题及其浅深模式。主题预览只保留标题，可横向滑动或拖动浏览，也支持左右按钮和键盘选择。密度、动态效果和透明材质可独立设置；此前明暗偏好自动迁移，本机偏好读取失败会安全回退。
- 外观恢复系统、浅色、深色的图文单选，保留整体圆角底座、内嵌选中块与轻微层次。固定且不超过四项的简短偏好／筛选共用同一组件；长选项使用下拉，窄屏不足时自动回退并保留选中值和焦点。
- 聊天和话题的中栏可折叠，文件和成员使用单一主列表，保留置灰的中栏按钮槽位，切换页面不会挪动导航；桌面详情侧栏独立滚动，手机详情整页显示。普通成员的五项主导航与管理员的空间入口按能力区分，未选对象时不残留旧详情。
- 个人设置按资料、外观、聊天、通知、隐私、表情及 Bot 分层；资料编辑、保存区和只读身份分别组织，邮件频率、地址与验证操作层级更清楚，手机个人首页可退出登录。
- 开关、下拉、滑块和对象菜单统一尺寸、键盘和焦点行为；长选择列表在手机上支持搜索与明确取消。
- 退出登录使用统一的圆角按钮与危险操作状态；个人设置和账号菜单均保持完整命中区及原有未保存内容保护。
- 修复进入表情设置就自动弹出管理窗口、关闭后跳到其他设置页的问题。管理窗口改为显式打开，关闭留在原页面；聊天中打开时保留会话、草稿与输入焦点。
- 个人资料明确保存，普通偏好显示真实保存状态；返回、浏览器历史和退出保护未完成内容。取消删除合集不再执行另一种删除。
- 私密直连创建后直接进入会话，在同一界面完成邀请、等待、交谈与结束；结束后可保存本机记录或直接导出。
- 话题可以从表单创建，各话题分别保留本次登录中的草稿与回复；从群聊打开话题不会改变群聊草稿的发送目标。
- 话题标题、状态和工具栏重新分层；成员行统一提供更多操作。群邀请支持搜索候选与多选，逐个提交，部分失败时保留未成功项供重试。
- 话题作为群聊子会话共用完整消息内容、图片/文件、表情、回复、反应、常驻、撤回和隐藏操作，上传期间可以继续发下一条；低频操作收进“话题详情”，输入器外围底板透明，仅输入器本体浮起；恢复本人消息底色，快捷操作嵌入消息行，修正成员目录纯文字头像偏移。
- 连续短消息使用首尾圆角、组内平直衔接的统一表面，减少重复轮廓；回复、未读和隐藏等语义边界保持清晰。阅读历史时新消息不会裁掉正在看的内容，分页导致分组变化时保持正文位置。
- Bot 设置按资料、连接、授权、凭据组织，提供现有私聊与群聊上下文授权入口；每项明确提交，不扩大 Token 权限或绕过会话授权。Echo 需求和公开征集可在同级标签间切换并保留草稿。
- 空间角色和可见范围使用可搜索的扁平成员行；列表／卡片切换、图标按钮和窄屏控制保持完整触控尺寸。

兼容与升级：无需数据库迁移，既有邀请、深链接、历史消息、文件引用和 P2P 本地存档继续适用。主题偏好仅保存在本机，不提供跨设备草稿或外观同步。两条通道的保存及授权边界保持不变。

群邀请复用现有单成员接口，不是原子批次；已成功添加的成员不会因其他项失败而回滚。

完整覆盖尚未核销，局部截图和自动化通过不等于全产品验收。发布前须完成真机软键盘、安全区域和辅助技术人工验收，记录性能限制并由维护者合并。发布与回滚遵循 [仓库流程](../../development/TESTING_AND_RELEASE.md)，本次开发不执行生产部署。
