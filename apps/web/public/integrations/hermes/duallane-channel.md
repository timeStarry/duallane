# DualLane Channel for Hermes

Stable Hermes instructions currently target DualLane Bot Gateway protocol v1
and SDK 0.15.0.

Canonical versioned prompt:

`/integrations/v1/hermes/duallane-channel.md`

Hermes uses the generic JavaScript SDK in this release; there is no claimed
official Hermes Adapter. Never put a Bot token in this URL.
